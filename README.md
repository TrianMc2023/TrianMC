## 🔱 ¡Hola! Soy Trian
Soy creador de códigos y sistemas para Bot Designer For Discord (BDFD). Me gusta desarrollar ideas, crear comandos, resolver errores y encontrar nuevas formas de mejorar los bots de Discord.

En este perfil comparto mis proyectos, códigos y recursos para que otros creadores puedan aprender, experimentar y desarrollar sus propias ideas.

🔧 ¿Qué hago?

💻 Desarrollo comandos y sistemas para BDFD.

🛠️ Busco soluciones a errores y problemas de código.

📂 Comparto proyectos y recursos en GitHub.

🎥 Trabajo en ideas para tutoriales y contenido educativo.

🎯 Mi objetivo

Seguir aprendiendo, mejorar mis habilidades y construir una comunidad donde podamos compartir conocimientos, desarrollar proyectos y crecer como creadores.
